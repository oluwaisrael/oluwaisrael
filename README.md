## 🎧 Music Hit Predictor

An ML project investigating whether acoustic characteristics can meaningfully predict the popularity of Afrobeats tracks.

The project originally explored Spotify data before moving to a Kaggle dataset because of Spotify API access restrictions.

### Evaluation

I used **5-fold cross-validation** and reported the result rather than forcing a successful narrative.

* Logistic Regression: **57.3%**
* Baseline: **55.2%**

The result was not strong enough to claim meaningful predictive power, making honest model evaluation part of the project.

🌐 **Live:** [Launch App](https://music-hit-predictor-kxitaremaxmairznaqbxuy.streamlit.app/)

# 🧭 Roam — Natural-Language Decision Engine

An ongoing product concept focused on helping people make decisions about **real places**.

Instead of simply searching for places, Roam is designed around questions such as:

The idea combines real-world data, natural-language input, constraints, ranking, trade-offs, and what-if decisions.

### Direction

Roam is part of my exploration into building **AI products around real-world decision making** rather than generic chatbot experiences.
